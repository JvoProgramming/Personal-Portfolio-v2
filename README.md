# Personal Portfolio v2

Johnny's personal website, built with Vite + React + TypeScript.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs to dist/
```

## Deploy

Hosted on Vercel. Vercel auto-detects Vite (build command `npm run build`, output `dist`), so no extra config is needed. Every push to `main` deploys to production; other branches get preview URLs.
